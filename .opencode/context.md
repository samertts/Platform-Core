# Platform-Core Context

Platform-Core is an enterprise-grade platform framework.

Primary goals:

* Modular architecture
* Offline-first execution
* Strong governance
* Registry-driven design
* Plugin extensibility
* Runtime isolation
* Long-term maintainability

The project is not a simple Python application.

Every change must preserve architectural integrity.

The Runtime layer is the execution foundation.

The Registry layer is the source of truth.

The Governance layer defines policies and validation.

Discovery is responsible for repository analysis.

Knowledge provides semantic understanding.

Automation contains repository automation and reporting.

Documentation is considered part of the product and should stay synchronized with implementation.

The project follows architecture-first development.

Whenever multiple implementations are possible, prefer the one that:

1. preserves architecture
2. minimizes coupling
3. maximizes extensibility
4. keeps backward compatibility
5. minimizes technical debt
