# Platform-Core Architecture

The project is organized around several major domains.

## Runtime

Responsible for execution, lifecycle, dependency injection, plugin loading, configuration and orchestration.

## Platform Core

Contains reusable platform services and enterprise capabilities.

## Registry

Maintains authoritative metadata for APIs, modules, services, devices, events and projects.

## Governance

Applies architectural, compliance and release policies.

## Knowledge

Provides semantic understanding of the platform.

## Discovery

Analyzes repositories and project structure.

## Automation

Executes automated analysis, reporting, certification and maintenance tasks.

## Reports

Contains generated architectural, governance and quality reports.

## Tests

Organized into:

* unit
* integration
* system

The architecture follows layered principles and should remain stable over time.
