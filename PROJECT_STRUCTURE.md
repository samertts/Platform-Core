# Purpose

This document defines the official structure of the Platform-Core repository.

Every directory has one responsibility.

No directory may contain unrelated functionality.

# Core Rule

The Kernel must remain minimal.

All optional functionality belongs outside the Kernel.

---

# Design Rules

- Everything has a Manifest.
- Everything has a Contract.
- Everything has Tests.
- Everything has Documentation.
- Everything has Metrics.
- Everything is Versioned.
- Everything is Replaceable.

---

# Repository Philosophy

Small Core.

Powerful Extensions.

Knowledge First.

Automation First.

Security By Design.

Documentation Always.
